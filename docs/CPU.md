# RP2A03 References:
Both Ricoh 2A03 and Ricoh 2A07 are MOS 6502 based without the decimal mode[^1].

| --- | --- | --- |
| Processor | 2A03 NES | 2A07 NES |
| Master clock | 21.477272 MHz | 26.601712 MHz |
| Internal clock divisor | 12 | 16 |
| CPU clock frequency | 1.789773 MHz | 1.662607 MHz |
